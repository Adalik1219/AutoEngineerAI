## Acceptance criteria (kazde ma jasny PASS/FAIL + meritelny dukaz)

Spolecne: Play Solo, reclaim (0 cizich dilu), telemetrie + RAW archiv jako run-003,
testy na trati +X s rezervou. Nevyhovujici vysledek = FAIL kriteria (ne cele F7.2).

### AC1 — Zataceni vlevo (steer -1)
- Postup: primy rozjezd na v≈25, drzet steer=-1 po 3 s (stream 0.2 s).
- PASS: |Δyaw| >= 0.15 rad a lateralni posun >= 8 coule za 3 s; dukaz: yaw
  vzorky + trajektorie (x,z) z telemetrie. Jinak FAIL.

### AC2 — Zataceni vpravo (steer +1)
- Stejny postup zrcadlove.
- PASS: stejne prahy jako AC1 + symetrie: |vysledek_L| vs |vysledek_R|
  v toleranci ±20 %. Jinak FAIL.

### AC3 — Opakovatelnost (relativni rozpeti)
- 3 opakovani pro kazdy smer (celkem 6 jizd), stejne podminky.
- Pro kazdy smer a pro kazdou velicinu zvlast (Δyaw; lateralni posun):
  R = (max - min) / |mean| * 100 %.
- PASS: R_yaw <= 10 % A R_lat <= 10 % v obou smerech.
  Jinak FAIL (+ vysetrit outlier, neusmernovat).
- Poznamka: prahove minima AC1/AC2 (0.15 rad / 8 coule) drzi |mean| mimo
  nulu, takze R je dobre definovane; pri nesplneni prahu AC1/AC2 se AC3 nehodnoti.

### AC4 — Uvolneni steering vstupu (vcetne ridiciho vystupu)
- A-Chassis 'New' rizeni je kinematicke (absolutni CFrame zapis, zadny momentovy
  kloub) — ridicim vystupem je uhel natoceni Arm.Steer, ne moment. Overuje se
  navrat uhlu, ne moment.
- Po ukonceni streamu (ticho na lince) sledovat 2 s.
- PASS soucasne: (a) |yaw_rate| < 0.02 rad/s do 1.5 s po uvolneni;
  (b) uhel natoceni kazdeho predniho Arm.Steer zpet na |uhel| < 0.5°;
  (c) AE_Steer -> 0/nil a AE_SteerC -> 0 (dead-man neutral);
  (d) vuz nepokracuje v zataceni. Jinak FAIL.

### AC5 — Ztrata spojeni a stale prikazy (explicitni odmitnuti)
- (a) Ztrata: 2 s ticha -> dead-man neutral do 1.0 s (AE_Throttle/AE_Steer 0,
  #AV moment 0). Dukaz: snimky atributu s casem.
- (b) Stale: stejny seq dvakrat s ruznou hodnotou -> druhy prikaz je
  EXPLICITNE odmitnut: nezmeni ZADNY ridici atribut (AE_Throttle/AE_Brake/
  AE_Steer), neprepise stav smycky (entry zustava), a neozivi rizeni po
  dead-manu (povel se starym seq po tichu -> stav zustava neutral, #AV = 0).
  Dukaz: before/after snimky atributu + stavu.
- PASS: obe casti splneny. Jinak FAIL. (F7.1: stale = CODE-VERIFIED,
  tento runtime test je jeho doplnenim.)

### AC6 — Occupant/seat autorizace (vychozi politika Occupant-only)
- Vychozi politika: manualni povely pres AEDriveCmd prijima server POUZE,
  je-li ve vozidle posazeny hrac (DriveSeat.Occupant ~= nil); bez posadky se
  povel ignoruje (zadny zapis, zadny pohyb). Pripadne uvolneni politiky je
  samostatne rozhodnuti, ne tichy ustupek.
- Test v obou stavech (Occupant vlastnost citne v kazdem kroku).
- PASS: obsazeno = povely funguji; neobsazeno = povely bez ucinku
  (atributy i fyzika beze zmeny). Jinak FAIL. (F7.1: validace NEIMPLEMENTOVANA.)

### AC7 — Server-authoritative ownership (GetNetworkOwner() == nil)
- Relevantni assemblies: 4 kola + 4 predni Arm.Steer + DriveSeat + nosne dilly
  slotu (overuje se ctenim GetNetworkOwner() na kazdem z nich).
- PASS soucasne: (a) vsechny relevantni dily maji GetNetworkOwner() == nil
  (server) po celou dobu steer jizd; (b) pokus klienta o prevzeti autority
  (testovaci zapis CFrame ridiciho dilu z klienta) je bez ucinku — server drzi
  uhel dle sveho prikazu v nasledujicich ticich; (c) AC1/AC2 PASS pri inertnim
  client-Drive. Jinak FAIL.

## Navrh server-side steering aktuatoru (ke kontrole, NEIMPLEMENTOVAT bez schvaleni)

### Vazba na A-Chassis (overeno ctenim sablony, Build 6C v1.5u2.1)
- Zdroj: `Drive` LocalScript, blok `[[Steering]]` (r. 322+), Tune `[[Steering]]`
  (r. 108-142). Aktualni hodnoty vozu: SteeringType='New', SteerRatio=15,
  LockToLock=2.6, Ackerman=0.9, SteerSpeed=0.05, ReturnSpeed=0.1,
  SteerDecay=330, MinSteer=10 %, FWSteer='None' (zadni rizeni vypnuto).
- Odvozene konstanty (stejny vzorec jako Drive r. 325-326):
  SteerOuter = (2.6*180)/15 = 31.2°; SteerInner = min(31.2-31.2*0.1, 31.2*1.2)
  = 28.08°.
- Klientsky Drive (r. 344-356) rampuje `_GSteerC -> _GSteerT` (SteerSpeed ven,
  ReturnSpeed zpet), pocita `sDecay = 1-min(|v|/SteerDecay, 1-MinSteer/100)`
  a aplikuje ABSOLUTNI CFrame zapis na kazde predni kolo (r. 363-380):
  `v.Arm.Steer.CFrame = Base.CFrame * Angles(0, -rad(_GSteerC * Inner/Outer *
  sDecay), 0)`, vnitrni/vnejsi kolo dle znamenka (Ackermann). Stav publikuje
  do `Values.SteerC` (r. 1175), kterou cte i SS6 Dynamic Friction (smyk).

### Fyzikalni princip navrhovaneho aktuatoru
- Stejny kinematicky princip jako A-Chassis 'New': natoceni prednich kol
  (cepi `Arm.Steer` kolem lokalni Y osy zakladny kola) meni rovinu kola;
  bocni sila pneumatiky (SS6 friction) pak staci vuz do zatacky.
  ZADNY novy momentovy kloub, zadna zmena geometrie podvozku.
- Rozdil oproti klientovi: zapis provadi SERVER (vlastnik fyziky), takze
  replikuje a pretrva; klientsky Drive zustava zdrojem NULA (mrtvy v teto
  session, jinak by jeho zapisy server zahazoval).

### Zpusob rizeni (ServerSteer.Step)
- Nova funkce `ServerSteer.Step(vehicle, steerT, dt)` (soucast ServerDrive
  modulu, stejny Heartbeat rytmus jako manual loop):
  1. Prikaz: `steerT` = uz validovany/clampnuty AE_Steer (-1..1) z AEDriveCmd
     (manual) nebo z replay-scenare (budouci T-steer).
  2. Stav `steerC` na vozidlo (modulova tabulka, analogie `_states` pohonu);
     rampa presne dle Drive: SteerSpeed ven / ReturnSpeed zpet, s `dt`.
  3. `sDecay` z rychlosti sedadla, prah MinSteer; konstanty SteerInner/Outer
     z Tune (ctene existujici Tune-cestou, zadny hardcode).
  4. Zapis: pro kazdou predni sadu {F, FL, FR} existujici ve voze doslovny port
     Drive r. 363-380 (vnitrek/vnejsek dle znamenka steerC; R-sada VYNECHANA,
     FWSteer='None').
  5. Publikace: `AE_SteerC` (aktual, pro telemetrii/AC4) + `Values.SteerC`
     (pro SS6 friction, stejny kanal jako klient) + `AE_Steer` zustava prikaz.
- Volano z: (a) manual-loop Heartbeat (stejny tick jako plyn/brzda);
  (b) budoucich replay-scenaru; NIKDY primo z klienta.

### Bezpecne uvolneni (release / stale / dead-man / prevzeti replayi)
- Nulovy prikaz (release, dead-man, ClearDriveInputs, stale-odmitnuti) =
  `steerT = 0`: steerC rampuje zpet pres ReturnSpeed (ZADNY skok na 0, zadne
  trhnuti volantem), CFrame se narovna, SS6 dostane SteerC -> 0.
- Stale povel se vubec nedostane do smycky (entry neprepsano, stav drzi
  posledni platny prikaz nebo neutral po dead-manu).
- Prevzeti replay-scenarem (activeVehicles): manualni entry se ignoruje,
  steerC prebira scenar; po konci scenare ClearDriveInputs (+ narovnani).
- Verifikace uvolneni = AC4 (uhel < 0.5°, yaw_rate, AE_SteerC = 0).
- Fail-safe: chybi-li `Arm.Steer` nebo `Base` (nekompletni stavba), Step vrati
  false + warn (zadny castecny zapis na jedno kolo); zadne tiche rizeni.
