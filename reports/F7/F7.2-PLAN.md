# F7.2 – Server-side steering (plan, 2026-11-18)

Vychodisko: F7.1 HEAD `d078ba9`; steer BLOCKED (viz F7.1-SCOPE-TRANSFER.md).

## Acceptance criteria (kazde ma jasny PASS/FAIL + meritelny dukaz)

Spolecne: Play Solo, reclaim (0 cizich dilu), telemetrie + RAW archiv jako run-003,
testy na trati +X s rezervou. Nevyhovujici vysledek = FAIL kriteria (ne cele F7.2).

### AC1 — Zataceni vlevo (steer -1)
- Postup: primy rozjezd na v≈25, drzet steer=-1 po 3 s (stream 0.2 s).
- PASS: |Δyaw| >= 0.15 rad a lateralni posun >= 8 coule za 3 s; dukaz: yaw
  vzorky + trajektorie (x,z) z telemetrie. Jinak FAIL.

### AC2 — Zataceni vpravo (steer +1)
- Stejny postup zrcadlove.
- PASS: stejne prahy jako AC1 + symetrie: |vysledek_L| vs |vysledek_R|
  v toleranci ±20 %. Jinak FAIL.

### AC3 — Opakovatelnost
- 3 opakovani pro kazdy smer (celkem 6 jizd), stejne podminky.
- PASS: rozptyl Δyaw i lateralniho posunu v ramci smeru <= ±10 %.
  Jinak FAIL (+ vysetrit outlier, neusmernovat).

### AC4 — Uvolneni steering vstupu
- Po ukonceni streamu (ticho na lince) sledovat 2 s.
- PASS: |yaw_rate| < 0.02 rad/s do 1.5 s po uvolneni + AE_Steer -> 0/nil
  (dead-man neutral); vuz nepokracuje v zataceni. Jinak FAIL.

### AC5 — Ztrata spojeni a stale prikazy
- (a) Ztrata: 2 s ticha -> dead-man neutral do 1.0 s (AE_Throttle/AE_Steer 0,
  #AV moment 0). Dukaz: snimky atributu s casem.
- (b) Stale: stejny seq dvakrat s ruznou hodnotou -> druhy bez ucinku
  (atributy se nezmeni). Dukaz: before/after snimky.
- PASS: obe casti splneny. Jinak FAIL. (F7.1: stale = CODE-VERIFIED,
  tento runtime test je jeho doplnenim.)

### AC6 — Occupant/seat autorizace
- Politika zdokumentovana v implementacnim planu (kdo smi ridit: occupant /
  kdokoli / jen unseated) + implementovana kontrola Occupant.
- Test v obou stavech (obsazeno / neobsazeno, Occupant vlastnost citne).
- PASS: pozorovane chovani v obou stavech = dokumentovana politika.
  Jinak FAIL. (F7.1: validace NEIMPLEMENTOVANA.)

### AC7 — Server-authoritative ownership bez client gyro zavislosti
- Behem vsech steer jizd: 0 cizich (client-owned) dilu (reclaim overen ctenim).
- Client Drive v session nebezi (capability-denial trva) — zataceni dosazeno
  ciste server-cestou.
- PASS: 0 cizich dilu + AC1/AC2 PASS pri inertnim client-Drive.
  Jinak FAIL.
